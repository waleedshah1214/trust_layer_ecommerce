# trust_layer_ecommerce
Problem: Different teams at an online marketplace get different numbers for the same metric, such as revenue, so nobody can trust the data. As companies add AI assistants that answer questions from this data, wrong numbers become more risky.

This project: cleans and tests e-commerce data, defines each business metric once, delivers a Power BI dashboard and a business recommendation, and measures how accurately an AI assistant answers questions from the data before and after the cleanup.
